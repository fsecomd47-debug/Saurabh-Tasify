# Code of Conduct

SaurabhTask is intended to be a respectful productivity community.

## Expected Behavior

- Be respectful and constructive
- Focus on productivity and accomplishment
- Help others succeed
- Report bugs and issues responsibly

## Unacceptable Behavior

- Harassment, threats, or hate speech
- Spam or impersonation
- Cheating or exploiting game mechanics
- Deliberate abuse of other players
- Sharing private user data
- Attempting to compromise system security

## Enforcement

Use reporting and blocking tools when necessary. Repeated violations may result in account suspension.
